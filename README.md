# Remove Paywall Bookmarklet

This is a simple bookmarklet to access content behind a paywall by using [12ft.io](https://12ft.io/)

Note: [removepaywall.com](https://removepaywall.com/) is not working consistently anymore.

Simply select and drag the JavaScript snippet below to the bookmarks bar to add it as a bookmark. To use it, click the bookmark while you are on a paywalled page.

```js
javascript:window.location='https://12ft.io/'+window.location
```
